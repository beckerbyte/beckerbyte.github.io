Wie das System aufgebaut ist.

Die Website wird als statische, responsive Oberfläche mit semantischem HTML, CSS, JavaScript und einer kleinen Build-Pipeline entwickelt. GitHub Pages stellt sie bereit; Cloudflare übernimmt die Auslieferung.
